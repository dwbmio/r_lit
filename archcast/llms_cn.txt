# archcast

name: archcast
version: 0.1.0
language: Rust (edition 2024)
category: CLI / 架构与流程汇报编译器
backends: cpu-simd-rayon（默认：memchr + wide::f64x4 + rayon + resvg/tiny-skia/gif）、webgpu-hybrid（可选 feature: gpu，原生 wgpu WGSL Compute Shader）

## 定位
面向 AI 与工程团队的确定性编译器：在「AI 友好的 YAML/JSON 规范」与「固定样式 HTML（内置浏览器 WebGPU/Canvas2D 流动动效）+ 根目录独立原版 SVG + 可选 PNG 光栅图与动态流光 GIF + 标准 Markdown/Mermaid 文档」之间双向转换。支持将既有 HTML+SVG 总览页逆向提取为规范 YAML 与 Markdown。

## 子命令
- `archcast render <INPUT> -o <DIR> [--format all|both|media|html|svg|md|png|gif] [--png] [--gif] [--gif-mode overlay|delta] [--scale <F32>] [--gif-scale <F32>] [--frames <N>] [--fps <N>] [--static-html] [--theme <ID_OR_PATH>] [--themes-dir <DIR>] [--backend auto|cpu|gpu] [--strict] [--json]`
  effects: pure
  io: input=input-path, output_dir=output-dir
  产物: <stem>.html (report-html), <stem>[-<diag_id>].svg (diagram-svg), <stem>.md (doc-markdown), 可选 <stem>[-<diag_id>].png (diagram-png), 可选 <stem>[-<diag_id>].gif (diagram-gif), archcast.log (log)
- `archcast theme list [--themes-dir <DIR>] [--json]`
  effects: read-only
- `archcast theme show <THEME> [--themes-dir <DIR>] [--json]`
  effects: read-only
  说明: 默认 stdout 输出完整解析后的 YAML，加 --json 输出结构化信封
- `archcast theme create <ID> [--from <THEME>] [--file <PATH>] [--display-name <NAME>] [--set <KEY=VALUE>...] [--force] [--themes-dir <DIR>] [--json]`
  effects: pure
  io: file=input-file
  产物: <themes_dir>/<ID>.yaml (theme-yaml)
- `archcast theme update <ID> [--file <PATH>] [--display-name <NAME>] [--set <KEY=VALUE>...] [--themes-dir <DIR>] [--json]`
  effects: pure
  io: file=input-file
  产物: <themes_dir>/<ID>.yaml (theme-yaml)
- `archcast theme delete <ID> [--themes-dir <DIR>] [--json]`
  effects: pure
- `archcast theme export <THEME> <OUTPUT> [--themes-dir <DIR>] [--json]`
  effects: pure
  io: output=output-file
  产物: <OUTPUT> (theme-yaml)
- `archcast extract <INPUT> -o <DIR> [--yaml-only] [--json]`
  effects: pure
  io: input=input-path, output_dir=output-dir
  产物: <stem>.yaml (spec-yaml), <stem>.md (doc-markdown), archcast.log (log)
- `archcast validate <INPUT> [--json]`
  effects: read-only
  io: input=input-file
- `archcast init <OUTPUT> [--title <TITLE>] [--json]`
  effects: pure
  io: output=output-file
  产物: <OUTPUT> (spec-yaml)
- `archcast info [--backend auto|cpu|gpu] [--json]`
  effects: read-only

## 规范 Schema (v1) 与主题 Schema (v1)
- 规范根节点：schema_version (1)、theme（可选主题 ID 或文件路径）、doc_title、title、lead[]、diagrams[]、flow_table
- 图表 diagram：id、heading、note、svg_title、canvas_title、subtitles[]、columns[]、edges[]、callouts[]、warning、footer
- 泳道列 column：id、title、width（可选）、cards[]
- 卡片 card：id、title、accent (Tone)、badge（可选）、align_with（可选对齐卡片 ID）、lines[]、subcards[]、footer
- 连线 edge：kind (direct|bus|loop_left|bottom_route)、from[]、to[]、label、bus_slot
- 接口表 flow_table：id、heading、note、groups[]（含 name、tone、rows[]）、hint
- 随包默认主题：starlink-light（默认）、obsidian-neon、paper-editorial、blueprint-ink、catppuccin-mocha
- 主题选择与查找优先级：命令行 --theme > 规范顶层 theme 字段 > 默认 starlink-light；查找顺序：直接文件路径 > 外部主题目录（--themes-dir / ARCHCAST_THEMES_DIR / $XDG_CONFIG_HOME/archcast/themes / ~/.config/archcast/themes）> 随包内置主题
- 主题自扩展与覆盖：YAML/JSON 支持 `extends: <父主题 ID>` 局部差异继承（深度合并，最多 4 层）；同名修改/新增可覆盖内置主题，执行 `theme delete` 自动恢复随包默认
- 主题 ID 约束：1..=64 字符，ASCII 字母数字开头，仅允许 [a-zA-Z0-9_-]
- 主题结构分组与 `--set <路径>=<值>` 全量字段：
  - 顶层：display_name, color_scheme (light|dark), is_dark (true|false), extends（YAML 内）
  - surface：page_bg, card_bg, card_border, card_shadow, svg_bg (#RRGGBB), node_bg, node_border, subcard_bg, subcard_border, callout_bg, callout_border, code_bg, codebox_bg, codebox_border
  - ink：page_fg, lead_fg, note_fg, code_fg, svg_title, svg_subtitle, svg_meta, col_header, node_title, node_text, node_mono, node_footer, subcard_title
  - chrome：toc_link, h2_accent, btn_bg, btn_fg, btn_border, btn_hover_bg, pill_bg, pill_fg, edge_spine, edge_stroke, edge_label_bg, edge_label_fg, badge_opacity, ver_bg_alpha
  - table：head_bg, head_fg, border, row_border, hover_bg, grp_bg, grp_fg, cnt_fg, small_fg, down_fg
  - warning：hint_bg, hint_fg, hint_accent, banner_bg, banner_border, banner_accent, banner_title, banner_body
  - tones：default, muted, blue, orange, green, emerald, amber, purple, gold, red
  - motion：pulse_hex（4 个逗号分隔 #RRGGBB）, beacon_red (#RRGGBB), beacon_green (#RRGGBB)

contract_version: 1
json_flag: --json
schema_command: archcast __schema
interactive: false
exit_codes: 0=ok, 1=runtime, 2=usage, 3=input, 5=partial
artifact_roles: report-html, diagram-svg, doc-markdown, diagram-png, diagram-gif, spec-yaml, theme-yaml, log
sidecar_log: <output_dir>/archcast.log（render 与 extract 子命令）
