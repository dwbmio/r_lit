# img_resize — 图片缩放与渠道纹理优化 CLI

- 用途: 按 `$engine_$channel.yml` 渠道配置进行游戏纹理体积优化、有效像素审计与图片缩放（PNG/JPG/WebP/BMP/GIF/TIFF），纯本地离线，无网络依赖
- 版本: 0.4.0
- 语言: Rust
- 类型: CLI 二进制
- 支持格式: PNG, JPEG, WebP, BMP, GIF, TIFF（输入）；PNG, JPEG, WebP（输出）

## 命令格式

```
img_resize optimize <PROFILE_YML> [PATH] [-o <DIR>] [--dry-run] [--report <FILE>] [--jobs <N>] [--json]
img_resize profile list [--json]
img_resize profile init <PRESET> [-o <FILE>] [-f|--force] [--json]
img_resize r_resize <PATH> [-o <DIR>] [选项] [--json]
```

## 子命令：`optimize`

- `<PROFILE_YML>`: `$engine_$channel.yml` 渠道配置文件路径（必填，位置参数）。文件名符合 `<engine>_<channel>.yml`（如 `godot_wx-minip.yml`）时自动推断引擎与渠道并继承内置默认值
- `[PATH]`: 输入图片或目录（可选，覆盖 YAML 内 `input:`）
- `-o, --out-dir <DIR>`: 输出目录（覆盖 YAML 内 `output:`；不传则原地覆盖；默认保留子目录结构）
- `--dry-run`: 仅执行有效像素分析与模拟压缩，不写图片文件
- `--report <FILE>`: 将完整 JSON 审计与压缩报告写至 FILE（artifact role=`report`）
- `--jobs <N>`: 并行线程数（默认按 CPU 核心数）

### 内置渠道预设（`$engine_$channel`）

- `godot_wx-minip`: Godot WASM 微信小游戏（max 1024px, 4px 对齐, PNG 量化 78..92 + PSNR>=38dB 兜底 + oxipng L3, JPG 82, WebP 82）
- `godot_qq-minip`: Godot WASM QQ 小游戏（max 1024px, 4px 对齐, PNG 量化 78..92 + PSNR>=38dB 兜底 + oxipng L3, JPG 82, WebP 82）
- `godot_dy-minip`: Godot WASM 抖音小游戏（max 1024px, 4px 对齐, PNG 量化 75..90 + PSNR>=37dB 兜底 + oxipng L3, JPG 80, WebP 80）
- `godot_zfb-minip`: Godot WASM 支付宝小游戏（max 1024px, 4px 对齐, PNG 量化 76..90 + PSNR>=37.5dB 兜底 + oxipng L4, JPG 80, WebP 80）
- `godot_mobile`: Godot 原生移动端 iOS/Android（max 2048px, 4px 对齐, PNG 无损 + oxipng L3 保留供 ASTC/ETC2 编码, JPG 88, WebP 88）
- `raw_png-jpg`: 通用 PNG/JPG 渠道（不强行缩放, PNG 量化 80..95 + PSNR>=39dB 兜底 + oxipng L4, JPG 84, WebP 84）

### 优化管线

1. 有效像素分析：`effective_pixel_ratio`、`bbox_area_ratio`、假透明检测（`min_alpha >= opaque_threshold`）、唯一色数（<=256 无损调色板）、灰度检测。
2. 布局安全清理：`strip_fake_alpha`（RGBA→RGB）、`zero_transparent_rgb` + `edge_bleed_px` 边界扩色（防 GPU 双线性采样黑边）；`trim_transparent` 默认 `false`（保护 Godot pivot/anchor/UV，可通过 `rules:` 对安全目录开启）。
3. 等比缩放与 `align_multiple` 对齐（绝不放大，默认 `lanczos3`）。
4. 格式路由：`opaque_png_to`、`alpha_png_to`、`jpg_to`、`webp_to`（`keep|png|jpg|webp`，默认 `keep` 以保护 Godot `res://` 引用）。
5. 本地编码：PNG（`imagequant` + `min_psnr_db` 无损回退 + `oxipng`）、JPG（剥离元数据）、WebP（有损 VP8 / 无损 VP8L）。
6. 体积不增保护（`no_regression: true`, `min_saving_pct: 1.0`）：未缩放/未裁切/未转格式时，若压完不更小则保留原文件。
7. Godot 默认保护规则（`inherit_default_rules: true`）：法线/ORM/遮罩/粗糙度/金属度/高度/凹凸/AO 贴图、`**/fonts/**`、`**/*_pixel*.*` 自动保持无损。

## 子命令：`profile`

- `img_resize profile list [--json]`: 列出全部内置渠道预设
- `img_resize profile init <PRESET> [-o <FILE>] [-f] [--json]`: 生成带注释的 `$engine_$channel.yml` 模板（`img_resize/profiles/` 目录亦有预置副本）

## 子命令：`r_resize`

- `<PATH>`: 图片文件或目录路径（必填）
- `-o, --out-dir <DIR>`: 输出目录（不传则原地覆盖，不可与 `-c` 同用）
- `-m, --max-pixel <SIZE>`: 最大边等比缩放（Lanczos3）
- `--rw <WIDTH>` + `--rh <HEIGHT>`: 精确尺寸调整（CatmullRom）
- `-c, --resize-config <FILE>`: 旧版多尺寸 YAML（`vec_size` / `vec_f` / `base_f`）
- `-j, --force-jpg`: 转成 JPG（质量 100），不做缩放

## 示例

```bash
img_resize profile list --json
img_resize profile init godot_wx-minip -o godot_wx-minip.yml
img_resize optimize godot_wx-minip.yml ./assets -o ./out --dry-run --json
img_resize optimize profiles/godot_dy-minip.yml ./assets -o ./out --report report.json --json
img_resize r_resize -m 800 image.jpg -o out/
```

## 备注

- `tinyfy` 子命令已禁用并隐藏（OpenSSL/musl 不兼容），请改用本地 `optimize`。
- 本地 PNG 量化使用 `imagequant`（GPL-3.0）。
- `optimize` JSON data: `{profile, dry_run, input, output_dir?, summary:{total, optimized, unchanged, skipped, failed, total_original_bytes, total_output_bytes, saved_bytes, saved_pct, fake_alpha_stripped_count, low_effective_pixel_count, quantize_fallback_count}, audit_hotspots:[...], results:[...]}`。

## 构建

```bash
cd img_resize && cargo build --release
```

## 机器调用契约 (r_lit CLI contract v1)

- 规范: 仓库根 docs/cli-contract.md；实现: crates/rlit_cli
- JSON: `--json` 为全局参数；stdout 只输出一个 JSON envelope（失败也是）；日志走 stderr
- envelope: {"contract":1, "ok", "tool":"img_resize", "version", "command", "data", "artifacts":[{"path","role","bytes","sha256"}], "error":null|{"code","kind","message"}, "warnings"?}
- 退出码: 0 成功, 1 运行时错误, 2 参数错误, 3 输入错误, 4 外部服务失败, 5 部分失败（ok=false，data 仍完整）
- schema: `img_resize __schema` 输出每个子命令的 JSON Schema (draft 2020-12)，含 x-cli（argv 还原、io 角色）、x-effects、x-env、x-stdin、x-note
- 非交互: 不会弹任何提示
- 副作用: optimize=pure, r_resize=pure, profile list=read-only, profile init=pure
