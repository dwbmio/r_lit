# R_LIT

- 用途: 面向中长期建设的 Rust 独立 CLI 工具、配套桌面工具与共享库集合仓库
- 定位: 所有 CLI binary 统一对齐 `crates/rlit_cli`（`--json`、`__schema`、退出码、`runlog`）；桌面/GUI 工具（`deskpet`、`maquette`、`group_vibe_workbench`、`mpreview`）同仓维护
- 仓库: https://github.com/dwbmio/r_lit
- 安装通道: https://r2.gamesci-lite.com/r_lit/<tool>/install.sh
- 制品中心: https://hfrog.gamesci-lite.com/api/release/softwares/<tool>

- 发布范围: 安装通道/制品中心仅适用于已发布工具；artifact-inspect 仅本地（macOS arm64 已验，Linux worker 制品未交付），不声称正式 Jenkins/R2/HFrog 发布或安装器；Jenkins hook 待评估
- artifact-inspect 路由: 根 .justfile 通用 build/install_loc 可路由到本 crate，固定 test-cli/lint-cli 未包含；通用路由不等于 CI toolMap/HFrog 登记
- artifact-inspect 契约: JSON 为 containers[].files[] 分层结构，HTML 元数据/文本/图像预览及单份 artifact-inspect.log；路径/名称抑制不是保密扫描或保密保证，大小不是网络量估算

## 目录

- artifact-inspect/ — 离线构建产物盘点（目录/ZIP/TAR.GZ/TGZ），按层 JSON 与 HTML 元数据/图像预览；仅本地 macOS arm64 验收，未正式发布；文档：artifact-inspect/README_CN.md、artifact-inspect/llms_cn.txt
- audiogen/ — 纯 Rust 游戏音频管线（程序化音效、MP3/WAV/FLAC 编码、MiniMax 异步任务）
- bulk_upload/ — 从 JSON 批量提取 URL 并上传至 S3 兼容存储
- deskpet/ — 无边框透明置顶 3D/Spine 桌面宠物（Bevy + 系统托盘 / 菜单栏常驻）
- gamereel/ — 把游戏协议回放渲染成短视频（Cargo workspace；CUDA + FFmpeg）
- group_vibe_workbench/ — 桌面协作工作台 (GPUI + Murmur P2P)
- img_resize/ — 图片缩放与压缩
- looplog/ — 本地日志摄入 / 查询工具，服务 AI 辅助联调（指南: looplog/WECHAT_AI_DEBUG_CN.md）
- mailctl/ — 多邮箱 IMAP/SMTP 分发器（按邮箱身份收发、白名单、发前确认、审计；`mailctl capabilities --json`）
- maquette/ — Kit 风格 low-poly 建模 + glTF 导出（GUI + headless CLI）
- mini_reg/ — Rust 原生小程序注册辅助；批次与断点持久保存；核实企业浏览器；人工确认
- mj_atlas/ — 精灵图集 / 打包工具，支持增量构建与多边形 mesh
- mpreview/ — Godot 模型预览与多角度相机截图工具
- phone_haul/ — 手机媒体迁移（Android adb+agent 与 iOS AFC/Photos.sqlite，BLAKE3 排重，`yyyy/MM` 归档）
- textexture/ — 艺术字图片生成（阴影 / 描边 / 渐变 / 发光 / 霓虹）
- ui-trim/ — 清理 AI 生成 UI 素材的伪透明背景并裁成 tight PNG
- crates/murmur/ — P2P 协作库 (iroh-net + Automerge CRDT)
- crates/rlit_cli/ — 共享 CLI 机器调用契约（`--json` envelope、`__schema`、退出码、`runlog`）

## 机器调用契约

- 规范: docs/cli-contract.md；共享 crate: crates/rlit_cli
- 已接入: artifact-inspect, mj_atlas, img_resize, ui-trim, textexture, bulk_upload, audiogen, phone_haul, mini_reg, looplog, mailctl, maquette-cli
- JSON: `--json` → stdout 只输出一个 envelope {contract, ok, tool, version, command, data, artifacts, error}
- 退出码: 0 成功, 1 运行时, 2 参数, 3 输入, 4 外部服务, 5 部分失败
- schema: `<工具> __schema` → 每个子命令的 JSON Schema + x-cli / x-effects / x-env / x-stdin
- runlog: `rlit_cli::runlog` 提供双 sink 缓冲日志并落盘到 `<output>.log`

## 构建

```bash
cd <tool_dir> && cargo build --release
```

- binary 目录约定: target/ 可删除；保留的本地可执行文件放 <tool>/out/<target-triple>/<binary>；正式制品由 Jenkins 发布到 R2/HFrog
- 仓库校验: `python3 scripts/check_repo.py` 或 `just check`

## AI 调试循环上下文

- 相关工具: bbc-ai-skill; https://git.7k7k.com/starlink/bbc-ai-skills; https://github.com/dwbmio/gamesci-cc-plugins
- 反复日志调试: 涉及本地 AI 日志 review、修复后重跑、技能 / 插件调试、微信小程序联调时，优先考虑 looplog/
- looplog 查询路径: looplog list --json; looplog grep <pattern> --json; looplog show <run_id> --json

各工具详情见对应子目录内的 README 和 llms.txt。
