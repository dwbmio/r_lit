# maquette

- 用途: 积木式 low-poly 3D 资产建模工具，提供桌面 GUI（`maquette`）与无头 CLI（`maquette-cli`），共用无窗口核心库
- 版本: 0.1.1
- 语言: Rust (edition 2024)
- 二进制: `maquette`（需 `gui` feature，默认开启）、`maquette-cli`（不依赖 GUI crate）
- features: `default = ["gui"]`、`gui`（启用 `bevy_egui`、`bevy_panorbit_camera`、`bevy_infinite_grid`、`bevy_mod_outline`、`rfd`）
- 引擎与界面: bevy 0.18、bevy_egui 0.39、bevy_panorbit_camera 0.34、bevy_infinite_grid 0.18、bevy_mod_outline 0.12

## 构建与测试

- GUI + CLI: `cd maquette && cargo build --release`
- 仅无头 CLI: `cd maquette && cargo build --no-default-features --bin maquette-cli --release`
- 无头单测: `cd maquette && cargo test --no-default-features`

## `maquette-cli` 子命令（遵循 `rlit_cli` 契约：全局 `--json` envelope、`__schema`、退出码 0-4）

- `export <input.maq> -o <out.glb|gltf> [--format glb|gltf] [--no-outline] [--outline-width 2.5] [--outline-color #000000]`
- `info <input.maq>`
- `validate <input.maq>`
- `render <input.maq> -o <out.png> [--width 512] [--height 512] [--background #181a1e] [--ambient 0.35]`
- `palette export <input.maq> -o <colors.json>`
- `palette import <input.maq> --from <colors.json> -o <out.maq>`
- `texture gen --prompt <text> -o <out.png> [--provider mock|rustyme] [--seed 0] [--width 128] [--height 128] [--no-cache]`
- `texture revoke <task_id> [--admin-url <url>]`
- `texture purge <queue> [--admin-url <url>]`
- `block list [--source local|hfrog|all]`
- `block get <id> [--source local|hfrog|all]`
- `block sync [--base-url <url>] [--runtime maquette-block/v1]`

## 模块结构

- 核心库（`src/lib.rs`，无窗口依赖）: `grid`、`mesher`、`project`、`export`、`render`、`palette_io`、`texture_meta`、`texgen`、`block_meta`
- CLI 入口: `src/bin/maquette_cli.rs`
- GUI 入口（`src/main.rs`）: `ui`、`camera`、`scene`、`block_library`、`block_composer`、`preview_mesh`、`multiview`、`export_dialog`、`slot_texgen`、`texture_registry`、`toon`、`history`、`autosave`、`session`、`float_window`、`notify`、`cloud_status`、`fonts`

## 环境变量

- `MAQUETTE_HFROG_BASE_URL`（默认 `https://hfrog.gamesci-lite.com`）
- `MAQUETTE_HFROG_RUNTIME`（默认 `maquette-block/v1`）
- `MAQUETTE_RUSTYME_REDIS_URL`、`MAQUETTE_RUSTYME_ADMIN_URL`
