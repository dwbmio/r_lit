名称: looplog
类型: 短时运行 Rust CLI + loopback 本地 HTTP 摄入口
用途: 为 AI 辅助联调收集和查询本地日志
存储: SQLite 数据库，默认路径来自平台 state/data 目录
保留周期: 默认最多 24 小时；serve、写入、查询、clean 都会触发清理
网络: 仅本地；MVP 阶段 HTTP 服务拒绝绑定非 loopback 地址
首个场景: 微信小程序开发联调日志
命令: serve, run, push, tail, view, config, list, show, grep, clean
配置: 唯一事实源 ~/.config/looplog/config.toml（--config 覆盖，XDG_CONFIG_HOME 生效）；[view] since/autostart/columns、[serve] addr/allow_lan/allow_cidrs、[[source]] name/tag/from/remote/unit/path/since/lines/sudo/reconnect/enabled
配置管理: view 页面「⚙ 配置」= 四组页面 API：GET /api/config、PUT /api/config、GET /api/sources、POST /api/sources/{name}/start|stop|restart；保存会写文件（.bak 备份）并重启运行中的来源；token 不写入配置文件
配置语义: 启停只改运行时；enabled 决定 autostart 与保存后是否拉起；view --column/--since 只覆盖本次启动初值
tail: 结构化日志源采集，不走 HTTP；--from journald（journalctl -o json，µs 时间戳 + PRIORITY + pid/unit）、--from nginx（解析 time_local/status/request_time/upstream_time）、--from logcat（adb epoch 时间、级别、pid/tid/tag，--serial 选设备）、--from file、--from cmd（兼容任意命令）；--remote 走 ssh，--sudo 加 sudo -n；--reconnect 指数退避并复用同一 run
tail时间语义: ts_ms 存日志源时间，ingest_ms 存入库时间；view 显示 |lag|>=250ms 的延迟标记，负数代表时钟漂移
tail清洗: journald 的 PRIORITY=6 但正文含 WARN/ERROR 时只升不降；剥离 ANSI 颜色码
view: 本地只读多栏日志窗口（loopback HTTP + 内嵌单页）；按 tag 分栏、合并时间轴、级别过滤、正则高亮、暂停/冻结、点击复制、时间线对齐（⏱ 默认开：滚动一栏，其他栏二分到同 ts 的第一行）、顶栏时间游标 + 每栏最新时间；--open 在 macOS 打开 Chrome --app 独立窗口
journald续读: 重连时用已入库最大 ts_ms 生成 --since @<epoch>.<usec>（+1µs），不丢不重；nginx/file 无锚点，重连按 --lines 重放可能重复
view接口: GET /; GET /api/lines?after_ms=&tags=&limit=&tail=1; GET /api/tags?since_ms=; GET /healthz
并发写: 多个 tail 进程可同时写一个库（WAL + busy_timeout + journal_mode 切换重试）
等级推断: tail 自动推断 ERROR/FATAL/PANIC→error, WARN→warn, nginx 5xx→error/4xx→warn, stderr→error
真机双流示例: examples/picboo-dev.sh 一条命令起 client/edge/api/gql 四路 tail + view
JSON输出: 全局 --json（`rlit_cli` envelope）+ `looplog __schema` + 标准退出码
HTTP端点: GET /healthz; POST /v1/runs; POST /v1/runs/{run_id}/lines; PATCH /v1/runs/{run_id}
日志行格式: application/x-ndjson，字段包括 ts, stream, level, event, text, meta
微信索引元信息: kind, project_path, appid, page, session, trace_id
微信扩展元信息: env, query, scene, compile_mode, tool, tool_version, base_lib_version, platform, device, network
SDK: TypeScript HTTP client 示例位于 sdk/ts/looplog.ts
适配样例: 微信小程序适配样例位于 adapters/wechat/wechat_adapter.ts
微信AI调试指南: WECHAT_AI_DEBUG_CN.md 说明微信开发者工具即时调试和 AI 自主 CLI 循环流程
SQLite后端: 默认 rusqlite + bundled SQLite
未来后端: pure-rust-sqlite feature 预留给 Limbo/Turso 风格纯 Rust 后端实验
相关AI工具: bbc-ai-skill; https://git.7k7k.com/starlink/bbc-ai-skills; https://github.com/dwbmio/gamesci-cc-plugins
推荐场景: 反复日志 review; AI 自主调试循环; 技能 / 插件调试; 微信开发者工具日志接入
