# bulk_upload

- 用途: 从 JSON 递归提取 URL，并发下载后上传到 S3 兼容存储
- 版本: 0.3.0
- 语言: Rust
- 二进制大小: 3-4MB (静态链接)

## 命令格式

```
bulk_upload jq [JSON文本 | @文件 | -] [--s3 <配置路径>] [--prefix <S3前缀>] [--concurrency <并发数>] [--json]
```

## 参数

- `JSON文本`: JSON 字符串、`@文件路径`，或 `-`/省略表示读 stdin（须管道输入），递归提取所有 HTTP/HTTPS URL
- `--s3` 可省略：省略时从同名 S3_* 环境变量读取凭证
- `--s3 <path>`: S3 凭证文件路径 (dotenv 格式)
- `--prefix <prefix>`: S3 key 前缀 (默认: 空)
- `--concurrency <N>`: 每批并发数，1-100（默认: 10）
- `--json`: stdout 输出一个 JSON envelope；data = {bucket, total_urls, total_success, total_failed, batches, files:[{source_url, s3_key, status, error}]}

## 配置文件格式

```env
S3_BUCKET=my-bucket
S3_ACCESS_KEY=your-access-key
S3_SECRET_KEY=your-secret-key
S3_ENDPOINT=https://your-account.r2.cloudflarestorage.com
S3_REGION=auto
```

## 兼容存储

AWS S3, Cloudflare R2, Aliyun OSS, iDrive E2, MinIO, 任何 S3 兼容端点 (path-style)

## 示例

```bash
bulk_upload jq '{"urls":["https://example.com/a.png"]}' --s3 .s3 --prefix assets/
cat urls.json | bulk_upload jq - --s3 .s3 --concurrency 10
bulk_upload --json jq '{"img":"https://example.com/photo.jpg"}' --s3 .s3
```

## 退出码

- 0: 全部成功（没有 URL 时也是 0，见 warnings）
- 2: 参数错误（参数非法，或没给输入且 stdin 是终端）
- 3: 输入错误（JSON 非法、S3 配置缺失或不完整）
- 4: 外部服务失败（所有 URL 都失败）
- 5: 部分失败（逐个结果见 data.files）

## 安装

```bash
# 一键安装（自动检测平台）
curl -fsSL https://r2.gamesci-lite.com/r_lit/bulk_upload/install.sh | bash

# 源码构建
cargo build --release
```

## 机器调用契约 (r_lit CLI contract v1)

- 规范: 仓库根 docs/cli-contract.md；实现: crates/rlit_cli
- JSON: `--json` 为全局参数；stdout 只输出一个 JSON envelope（失败也是）；日志走 stderr
- envelope: {"contract":1, "ok", "tool":"bulk_upload", "version", "command", "data", "artifacts":[{"path","role","bytes","sha256"}], "error":null|{"code","kind","message"}, "warnings"?}
- 退出码: 0 成功, 1 运行时错误, 2 参数错误, 3 输入错误, 4 外部服务失败, 5 部分失败（ok=false，data 仍完整）
- schema: `bulk_upload __schema` 输出每个子命令的 JSON Schema (draft 2020-12)，含 x-cli（argv 还原、io 角色）、x-effects、x-env、x-stdin、x-note
- 非交互: 不会弹任何提示
- 副作用: jq=external；x-env: S3_BUCKET, S3_ACCESS_KEY, S3_SECRET_KEY, S3_ENDPOINT, S3_REGION；x-stdin: JSON 文档
