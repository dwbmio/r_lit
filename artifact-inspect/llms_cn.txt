# artifact-inspect
- 用途：有界、离线盘点构建目录、ZIP、TAR.GZ、TGZ，支持嵌套 ZIP 和安全预览
- 版本：0.1.0
- 语言：Rust
- 包名：artifact-inspect
- 二进制：artifact-inspect
- 构建：cd artifact-inspect && cargo build --release
- 输入：目录、ZIP、TAR.GZ、TGZ；拒绝符号链接输入
- TAR 根项：仅原始名称严格为 . 或 ./ 的目录条目免于空路径拒绝且不进入清单；其他目录仍校验路径；拒绝空路径非目录；根标记可选；ZIP 检查不变
- 嵌套输入：任意路径下带 .zip 名称或 ZIP 签名的普通文件；有界内存；默认最大深度 4；损坏嵌套 ZIP 记录 nested_zip_invalid
- 归档完整性：普通 ZIP 成员读取至 EOF 验证大小/解压/CRC；TAR.GZ 解码器排空至 gzip 尾部；损坏外层输入退出 3 且不写 JSON/HTML 成功报告
- 输出：指定 --output-dir 下的 artifact-inspect.json、artifact-inspect.html、artifact-inspect.log
- 输出保护：目录输入的后代不可作为输出；JSON/HTML/log 符号链接、硬链接、非普通目标和输入文件别名以退出码 2 拒绝；普通文件原子替换且不跟随链接
- 网络：不访问
- 执行：绝不执行归档或构建产物内容
- 抽取：不向磁盘抽取归档，不写输入目录
- 报告结构版本：1

## 命令格式
```
artifact-inspect <INPUT> --output-dir <DIR> [限额] [--json]
artifact-inspect __schema
```

## 限额
- --max-entries：100000
- --max-total-raw-bytes：2000000000
- --max-nested-bytes：67108864
- --max-depth：4
- --max-preview-bytes：65536
- --max-total-preview-bytes：8388608
- --max-image-pixels：16777216

## 报告字段
- 容器：id、逻辑路径、类型、深度、父容器、文件、问题、汇总
- 文件：container_id、container、relative_path、kind、raw_bytes、zip_compressed_bytes、preview
- 汇总：file_count、raw_bytes、zip_compressed_bytes、preview_count、suppressed_preview_count
- zip_compressed_bytes：ZIP 条目压缩数据量；目录和 TAR.GZ 成员为 null
- 计数口径：容器各自独立，不提供跨层字节合计
- 传输口径：ZIP 条目压缩数据不含归档开销，不等于网络传输量
- 引擎格式：Godot/Unity 只分类不解析，不声称资产溯源

## 预览安全
- 位图：PNG/JPEG/GIF/WebP；检查尺寸并验证解码；限制像素和字节；使用惰性 data URI
- 文本：有界 UTF-8；HTML 转义
- 主动内容：HTML/JavaScript/SVG 只显示转义文本
- 敏感内容：private/secret/credential/token 路径、任意 *.env、.env.*、.envrc、私钥和密钥库使用 suppressed_sensitive，不含内容；敏感嵌套容器继承抑制并保留路径/大小
- HTML：独立离线；CSP default-src none；无脚本或外部资源
- 链接：不跟随输入/归档符号链接及 TAR 硬链接

## 机器调用契约（r_lit CLI contract v1）
- 规范：仓库根目录 docs/cli-contract.md
- JSON：--json 只输出一个信封；日志进入 stderr
- 信封：{contract:1, ok, tool, version, command:"", data, artifacts, error, warnings?}
- data：报告路径、输入、issue_count、逐容器汇总、大小口径、引擎格式限制
- artifacts：inventory-json、inventory-html、log，含 path/bytes/sha256
- schema：artifact-inspect __schema
- effects：pure；只写声明的输出目录
- 退出码：0 成功，1 运行期，2 参数，3 输入，4 外部保留，5 部分失败保留
